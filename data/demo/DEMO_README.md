# TrustShield Canonical Demo Dataset

## 1. Overview
This directory contains the canonical operational evaluation outputs generated for the **TrustShield UEBA Security Operations Center (SOC) Dashboard**.

- **File**: `data/demo/trustshield_demo_results.csv`
- **Rows**: 1,080 activity records
- **Entity Coverage**: 60 unique enterprise employees across 18 chronological test days (2026-06-12 to 2026-06-29)

---

## 2. Source Data & Model State Pipeline

The canonical demo dataset was generated by running the unified, inference-only pipeline:
```bash
python src/run_trustshield.py --input data/evaluation/test_input.csv --output_dir data/demo
```

### Upstream Model State & Components
1. **Raw Source**: Chronological test split `data/evaluation/test_input.csv` (ground truth withheld).
2. **Adaptive EWMA Baseline**: Warm-started from historical training state (`models/training_baseline_state.pkl`) learned over the 60-day training window.
3. **Pre-Trained Anomaly Models**:
   - `models/scaler.pkl`: StandardScaler fitted on TRAIN.
   - `models/iforest.pkl`: Isolation Forest fitted on TRAIN.
   - `models/autoencoder.pkl`: PyTorch Autoencoder fitted on TRAIN with fixed reconstruction threshold `0.870013`.
4. **Production Decision Engine**: Consensus-Gated Escalation Policy:
   - Security Tampering $\rightarrow$ **Alert**
   - 3-Model Consensus $\ge 2$ $\rightarrow$ **Alert**
   - 3-Model Consensus $= 1$ $\rightarrow$ **Log**
   - 3-Model Consensus $= 0$ $\rightarrow$ **Monitor**
5. **Explainable AI**: SHAP tree-explainer with fallback baseline-deviation evidence chains and local reliability scoring.

---

## 3. Ground-Truth Sanitization

In accordance with strict operational SOC guidelines:
- Evaluation ground-truth labels (`is_insider_ground_truth`, `insider_scenario`) are **completely stripped** from `trustshield_demo_results.csv`.
- Offline evaluation metrics are computed separately via research evaluation scripts (`src/evaluate_system.py`, `TRUSTSHIELD_V2_FINAL_RESEARCH_EVALUATION.md`).
